# Security

Please do not report vulnerabilities in public issues. Use GitHub's private reporting instead:
**Security → Report a vulnerability** in this repository. Describe what you found, how to reproduce it and which
version you run (Settings → Help shows it).

Fixes ship as a new release. Security releases say “Security” in their title; Kaveyl Wiki then shows admins a red
hint at the top right (Settings → Notifications → Updates).

Only the latest release is supported.
